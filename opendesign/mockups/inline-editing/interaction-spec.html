Design specification for replacing popup text editing with true inline editing on the Resume Canvas Editor.

7. Implementation Notes

  • Use contentEditable="true" on the existing text elements instead of swapping to a <textarea>.
  • Keep the element's existing CSS classes and typography — editing must be WYSIWYG (visually identical to read mode).
  • Use document.execCommand for basic formatting (bold, italic, underline) for simplicity; consider a lightweight ProseMirror or Tiptap integration for robust rich-text if undo/redo fidelity matters.
  • Drag and drop (dnd-kit) must be disabled while any field is in editing mode to prevent conflicts.
  • The edit queue debounce (2 seconds) should fire on blur and on input events to batch rapid edits.
  • For the link input, use a small floating bar positioned above the selection, similar to Notion's link popover.
  • Selection state should be stored in React state and communicated to the FloatingToolbar and SortContext to disable drag during edits.
